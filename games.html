Unslow

by Josiah and Jonathan Main

In Summer '24 I made this game for the Polymars x ScoreSpace Speed Jam. I custom-wrote a rudimentary game engine in JS for this and did all the code and sprites. It has a healthy level of jankiness and is hard to control, but I think it's cute and I want to exhibit it to show where I was in my game development journey at the time. Also, my brother wrote the music! See the itch page

VS Craig: A Blockman Bossfight

by Josiah Main

This is a game I made while taking CMU's 98-127 Intro to Game Development in Unity student-taught course in Spring '26. I learned to do a lot of things: Unity C# scripting, modeling, animation/rigging, procedural animation, shader graphs - and I also wrote the music for it! Thanks to my lovely teachers Jeffrey, Dario, Jingxuan, and Shangyi! And here's the itch page

Michael Cycle 3D

by Josiah and Jonathan Main

In 2023 (10th grade) I spent a year doing my very best to replicate a popular racing game (hmm i wonder which one) in Scratch! To do this, I followed griffpatch's 3D raytracing tutorials and then extended it with my own engine, including my own polygon filler, 3D hitboxes, computer-controlled opponent path editor, and I also prerendered the models to make it faster at runtime. The best way to play it is probably TurboWarp, but you can use the native Scratch page too.

Honey Haven (dir. Alyssa Dang & Zuri Ye)

Josiah Main, minigame programmer

This is a visual novel which is a psychological thriller set in a cozy animal village. I made a carrot delivering minigame in Godot. We won GCS Gold for Spring '26! Huge shoutout to the great team leaders Zuri and Alyssa (WOW AURAAAA) and here is the itch page

Lockdown in Cell Block 9

RMHS Game Creation Society

In high school my friends and I designed this board game. It's a goofy game about escaping from prison. Players compete to be the fastest one out of the jail using ridiculous methods like digging tunnels with spoons. My site has a page for it.
